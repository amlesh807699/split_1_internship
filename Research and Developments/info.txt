# Research and Development Report

## Prodesk IT — Digital Marketing & Technology Website

### 1. Project Overview

The objective of this project was to design and develop a modern, professional, responsive website for **Prodesk IT**, a digital marketing and technology company.

The website was designed to present the company's services, capabilities, business information, contact details, and overall digital presence in a clear and professional manner.

The development process followed a structured approach starting with research and analysis, followed by UI/UX design, website development, content integration, responsive implementation, and final review.

---

# 2. Research Phase

## 2.1 Existing Website and Brand Review

The first step of the project was to review the existing Prodesk IT website and understand the company's existing digital identity.

During the review, the following elements were analyzed:

* Existing company branding
* Company logo
* Logo colors
* Website structure
* Services offered
* Company information
* Contact information
* Office locations
* Existing website content
* Social media and external links
* Overall visual identity

The purpose of this research was to make sure that the new website remained consistent with the company's existing identity while improving its visual presentation and user experience.

---

## 2.2 Brand Color Research

During the brand review, it was observed that the Prodesk IT logo primarily uses **black and yellow**.

Based on this observation, the website's visual design was developed around a similar color direction.

The selected visual approach focused on:

* Black for strong branding and contrast
* Yellow as an accent color
* White/light surfaces for readability
* Neutral shades for supporting text and backgrounds

The purpose of using the existing brand colors was to maintain consistency between the company's logo and the website.

This helped create a recognizable visual connection between the company's existing identity and the newly developed website.

---

# 3. UI/UX Design Research

## 3.1 Figma Design

After completing the initial research, the next stage was creating the website's UI design in **Figma**.

The Figma design was used to plan the website before beginning the actual development.

The design process included:

* Navigation bar
* Hero section
* Company introduction
* Services section
* Company statistics
* Why Choose Us section
* Call-to-action section
* Footer
* Office location information
* Social media links

The Figma stage helped establish the visual structure, spacing, typography, layout, color system, and overall user experience before implementation.

---

## 3.2 Website Layout Planning

The website was planned as a single-page corporate website with clearly separated sections.

The main structure was:

1. Home
2. About
3. Services
4. Company Information
5. Why Choose Us
6. Contact / CTA
7. Footer

The navigation menu was also designed to allow users to quickly move between these sections.

---

# 4. Website Development

After completing the UI design, the design was converted into a functional website using HTML, CSS, and JavaScript.

### Technologies Used

* HTML5
* CSS3
* JavaScript
* Figma for UI/UX design
* Git/GitHub for project version control

HTML was used to create the structure of the website.

CSS was used for:

* Layout
* Colors
* Typography
* Spacing
* Responsive design
* Animations
* Hover effects
* Dark/light theme
* Navigation styling
* Cards and sections

JavaScript was used for interactive functionality such as:

* Theme switching

* Dynamic UI behavior

A dedicated CTA section was developed to encourage users to start a project or contact the company.

**"Ready to Build Your Digital Future?"**

---

# 13. Responsive Design

The website was developed with responsive behavior in mind so that the layout can adapt to different screen sizes.

The responsive design covers:

* Desktop
* Laptop
* Tablet
* Mobile

The navigation system also includes a mobile menu so that navigation remains accessible on smaller screens.

Content sections, cards, buttons, typography, and spacing were adjusted through CSS media queries to maintain usability across different viewport sizes.

---

# 14. Theme Functionality

A theme toggle was also implemented as part of the website interaction.

The website supports:

* Light theme
* Dark theme

JavaScript is used to control the theme interaction, while CSS variables are used to manage the visual colors.

This approach makes the theme system easier to maintain because colors can be controlled centrally through CSS variables.

---

# 15. Accessibility Considerations

During development, basic accessibility practices were also considered.

Examples include:

* `alt` text for images
* `aria-label` for navigation and buttons
* Semantic HTML elements
* Proper heading structure
* Readable color contrast
* Keyboard-accessible buttons and links

These practices help make the website easier to understand and interact with for a wider range of users.

# 17. Key Research Findings

The research and development process resulted in several important design decisions:

| Research Finding                                | Development Decision                  |
| ----------------------------------------------- | ------------------------------------- |
| Existing logo uses black and yellow             | Black/yellow visual direction adopted |
| Company already has an established identity     | Existing logo retained                |
| Users need quick access to services             | Dedicated service cards created       |
| Company information should be visible           | Statistics section added              |
| Company differentiators need clear presentation | Why Choose Us section created         |
| Office information is useful for visitors       | Locations added to footer             |
| External digital presence should be accessible  | Social and official links integrated  |
| Users need a clear next action                  | CTA section added                     |
| Users access websites from different devices    | Responsive design implemented         |
| Different users may prefer different themes     | Light/dark theme functionality added  |

---

# 18. Conclusion

The Prodesk IT website was developed through a research-driven design and development process.

The project began with an analysis of the company's existing website and brand identity. The company's logo and visual characteristics were studied before creating the new interface in Figma.

After the UI design was finalized, it was implemented using HTML, CSS, and JavaScript. Company-specific information was researched from the official website and integrated into appropriate sections.

Additional sections such as company statistics and the **Why Choose Us** section were created to improve the presentation of important business information.

The final website also includes the official company logo, office locations, services, contact information, external links, responsive layouts, CTA sections, and theme functionality.

Overall, the development process followed a structured workflow of:

**Research → Analysis → UI/UX Design → Development → Content Integration → External Links → Responsive Implementation → Testing**

This approach helped transform the initial website requirement into a structured, professional, and functional digital marketing website.
